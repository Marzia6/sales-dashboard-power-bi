# Sales Dashboard | Power BI

## Project Overview
This project presents a sales dashboard developed using Microsoft Power BI. It is designed to help users explore sales performance and understand business data through interactive visualizations.

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis

## Project Features
- Visual representation of sales data
- Interactive dashboard for exploring business performance
- Charts and visual summaries to support data-driven decisions

## Project File
The Power BI report is available in this repository:

`Sales_Dashboard.pbix`

Download the file and open it using Microsoft Power BI Desktop to explore the report.

## How to Use
1. Clone or download this repository.
2. Open `Sales_Dashboard.pbix` in Power BI Desktop.
3. Explore the available report pages and interactive visualizations.

## Project Purpose
The purpose of this project is to practice data analysis and dashboard development using Power BI, with a focus on presenting business information in a clear and useful format.
